## Longer (Reddit / HN)

**Title options**

- Place any Mac window on any grid span in two keypresses  
- Quintile: keyboard N×M grid window placement for macOS (not auto-tiling)  
- Show HN: Place any Mac window on any grid span in two keypresses  

**Body**

```text
Most Mac window tools stop at halves, thirds, and quarters. I wanted an arbitrary N×M grid and a way to put a window on any rectangular span from the keyboard only — without auto-tiling and without disabling SIP.

Quintile:
- ⌃⌥G, two cells → span any rectangle on the grid
- presets for thirds / quarters / sixths
- three grid profiles per display
- menu bar app, Accessibility only, MIT, Developer ID signed & notarized

Install:
  brew install --cask stefanopineda/quintile/quintile

Laptop: start with thirds (⌃⌥[ ] \). The 5×2 default shines when you have width (external / ultrawide).

Not a yabai or AeroSpace replacement — you place windows; nothing rearranges for you.

Repo: https://github.com/stefanopineda/quintile
```

## Reply snippets

**Laptop skepticism**

```text
Fair — on a 16" I use thirds first (⌃⌥[ ] \). The 5×2 / span picker is for when you have width (external or ultrawide). Spaces is still fine for whole-workspace switching; Quintile is place-this-window, not auto-tile.
```

**vs Rectangle**

```text
Rectangle is great for halves/thirds. Quintile is for “put this on columns 1–3 of a 5-wide grid” from the keyboard — complement, not a must-replace.
```

**Install / Accessibility stuck**

```text
Menu bar ⊞! → grant Accessibility. If the toggle already looks ON: OFF then ON, then Check Again in the Quintile window. No Screen Recording needed.
```
