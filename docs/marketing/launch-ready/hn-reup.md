## Text (optional — paste as first comment if title-only submit)

You don't need to settle for sloppy window tiling.

Most Mac tools stop at halves/thirds/quarters, or they take over layout (yabai-style auto-tile) and often want SIP disabled. I wanted the opposite: **I** place the window, on any rectangular span of a grid I choose, from the keyboard only.

Quintile:
- ⌃⌥G, two cells → span any rectangle on an N×M grid
- presets for thirds / quarters / sixths
- three grid profiles per display
- Accessibility only — no SIP, no private APIs
- menu bar app, MIT, Developer ID signed & notarized

Install:
  brew install --cask stefanopineda/quintile/quintile

Laptop: start with thirds (⌃⌥[ ] \\). Arbitrary grids shine when you have width.

Not a Spaces/yabai replacement — place-this-window, not rearrange-everything.
